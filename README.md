#  Meu Salão - Sistema Web

Sistema web desenvolvido para gerenciamento de salões de beleza.

##  Funcionalidades

- Cadastro de clientes
- Agendamento de serviços
- Organização administrativa
- Interface responsiva

##  Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

##  Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos em Desenvolvimento Web e criar uma solução moderna para gestão de salões de beleza.
